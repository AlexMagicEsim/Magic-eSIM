# Magic eSIM — Marketing Scenario Library

Each scenario is a ready **slide sequence**. Default output for
"Сделай сторис для Magic eSIM" = a **3-slide set**: hook → value → offer/CTA.
Keep each slide ≤ 40–60 words, one headline, ≤ one CTA. Promo only where noted.

Suggested template per slide in brackets — swap to fit the audience.

## 1. Прогрев (warm-up)
1. Hook: `Скоро отпуск? 🌴` — «Рассказываю, как не остаться без интернета» [beach]
2. Value: «Ставлю eSIM ещё дома — и всё готово к поездке» [airplane]
3. CTA: «Выбрать тариф → magicesim.store» [brand]

## Sequencing rules
- Slide 1 hooks, slide 2 delivers one clear value, final slide has exactly one CTA.
- Put the promo on the offer slide only; never repeat `FRIENDS10` on every slide.
- Never mix two CTAs on one slide.
- Reviews/claims must be real & confirmed (see brand rules) — otherwise skip.
