How to install an eSIM on Android

Android brands name their settings differently, but the steps are the same everywhere: find where SIMs are managed, add an eSIM with its QR code or by hand, then choose it for mobile data at your destination. You need an internet connection to install — Wi-Fi is easiest.

On this page

  1. Find where SIMs are managed
  2. Install the eSIM
  3. At your destination — turn on data
  4. If something goes wrong
  5. Questions

Find where SIMs are managed

The SIM settings usually live in one of these places — names vary by brand and Android version:

  • Google Pixel: Settings → Network & internet → SIMs → Add SIM → Set up an eSIM.
  • Samsung Galaxy: Settings → Connections → SIM manager → Add eSIM (on older One UI versions: SIM card manager → Add mobile plan).
  • Other brands: look for «Mobile network», «SIM cards» or «Connections» in Settings.

If there is no option to add an eSIM anywhere, check whether your phone supports eSIM.

Install the eSIM

  1. Show your eSIM's QR code on another screen.
  2. Start adding an eSIM as above. Samsung: tap Scan QR code (older One UI: Add using QR code) and scan the code. Pixel: follow the instructions on the screen.
  3. No QR code to scan? On Samsung with older One UI, tap Add using activation code and enter the details provided with your eSIM; on newer versions, follow the on-screen option for entering an activation code.
  4. Confirm, and wait until the installation finishes.
  5. Rename the eSIM, for example to «Travel».

At your destination — turn on data

  1. Make sure the eSIM is turned on. Pixel: Settings → Network & internet → Mobile network → the eSIM → Use this SIM.
  2. Choose the eSIM as the SIM for mobile data. Pixel: Settings → Network & internet → SIMs → Mobile data. Your main SIM can stay on for calls and texts.
  3. Turn on roaming for the eSIM. Samsung: Settings → Connections → Mobile Networks → Data Roaming. Travel eSIMs usually connect through partner networks, which the phone treats as roaming.
  4. If you do not want charges from your home operator, turn off data roaming on your main SIM.
  5. Give the phone a minute or two to register on a local network.

If something goes wrong

Check the data SIM and roaming on the eSIM, toggle airplane mode, then restart. The full checklist is in eSIM not working.

Do not delete the eSIM while troubleshooting: its QR code may be single-use.

Questions

My Android phone has no «Add eSIM» option. What now?

Look under every SIM-related menu — the name differs by brand. If no option to add or download an eSIM exists anywhere, the phone (or this regional version of it) probably does not support eSIM.

Can I use the eSIM and my physical SIM at the same time?

On phones that support dual SIM with eSIM, yes: choose the eSIM for mobile data and keep the physical SIM for calls and texts.

Do I need to set an APN?

Only if your plan's details list an APN: then check that it matches in the eSIM's settings.
