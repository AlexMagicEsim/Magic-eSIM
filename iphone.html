Как установить eSIM на iPhone

Перед установкой убедитесь, что iPhone поддерживает eSIM и подключён к Wi-Fi.

Через QR-код

  1. Откройте Настройки → Сотовая связь.
  2. Нажмите Добавить eSIM.
  3. Выберите Использовать QR-код.
  4. Отсканируйте QR-код из заказа.
  5. Дождитесь добавления eSIM и включите новую линию.
  6. Для поездки включите Роуминг данных на этой eSIM.

Вручную через LPA

  1. Откройте Настройки → Сотовая связь.
  2. Нажмите Добавить eSIM → Использовать QR-код.
  3. Выберите Ввести данные вручную.
  4. Введите SM-DP+ адрес и Activation Code из заказа.
  5. Сохраните eSIM и дождитесь завершения установки.
  6. Включите мобильные данные через новую eSIM.
Если установка не начинается, проверьте подключение к Wi-Fi, поддержку eSIM на устройстве и отсутствие операторской блокировки.
