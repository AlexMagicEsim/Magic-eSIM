# Служебные параметры, не меняющие содержимое страницы.
#
# ПОЧЕМУ. Замер Вебмастера 2026-08-29: в индексе шесть URL-дублей —
# /esim/thailand/?keep=1, /esim/usa/?keep=1, /esim/uae/?v=2, /?country=VN,
# /?cb=<число>, /?nl=<число> — при скромном обходе (234 успешных ответа
# робота за период). Директива склеивает их с чистым адресом вместо того,
# чтобы тратить обход на разные документы с одинаковым содержимым.
#
#   keep, v  — служебный флаг и версия ассетов
#   cb, nl   — обход кеша, значение всегда разное
#   country  — предвыбор страны на главной; каноническая страница страны
#              живёт по адресу /esim/<страна>/ и ранжируется именно она
#
# Директива понимается только Яндексом. В Google ту же роль играет canonical,
# который на всех страницах уже стоит и самоссылается.
Clean-param: keep&v&cb&nl&country
