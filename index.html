Как установить Magic eSIM

Выберите устройство — подробная инструкция раскроется по нажатию.

🍎 Инструкция по установке Magic eSIM на iPhone

Что будет в письме

  • ссылка на установку eSIM;
  • QR-код для установки eSIM;
  • данные для ручной установки, если они предусмотрены тарифом;
  • информация по тарифу.

Если письмо не пришло сразу, проверьте папки Спам, Промоакции, Рассылки или Нежелательная почта.

🍎 Инструкция для iPhone

Перед установкой

Убедитесь, что iPhone поддерживает eSIM, телефон не заблокирован под конкретного оператора, у вас есть стабильный интернет через Wi-Fi, и вы открыли письмо со ссылкой установки или QR-кодом.

⚠️ QR-код eSIM обычно можно использовать только один раз. Не удаляйте eSIM после установки, если тариф ещё нужен.
Установка eSIM по ссылке
  1. Откройте письмо прямо на iPhone.
  2. Нажмите на ссылку установки eSIM.
  3. Подтвердите добавление eSIM.
  4. Дождитесь завершения установки.
  5. Назовите линию Magic eSIM.
  6. Для звонков и SMS оставьте основной номер.
  7. Для мобильных данных выберите Magic eSIM перед использованием тарифа.
Установка eSIM через QR-код
  1. Откройте письмо с данными eSIM на другом устройстве: компьютере, планшете или втором телефоне.
  2. На iPhone откройте Настройки.
  3. Перейдите в Сотовая связь.
  4. Нажмите Добавить eSIM.
  5. Выберите Использовать QR-код.
  6. Отсканируйте QR-код из письма.
  7. Нажмите Продолжить.
  8. Дождитесь завершения установки.
  9. Назовите линию, например Magic eSIM или Travel.
  10. Для звонков и SMS оставьте ваш основной номер.
  11. Для мобильных данных выберите Magic eSIM только тогда, когда будете готовы пользоваться тарифом.
Как включить интернет через eSIM на iPhone
  1. Откройте Настройки.
  2. Перейдите в Сотовая связь.
  3. Нажмите Сотовые данные.
  4. Выберите Magic eSIM.
  5. Вернитесь назад и откройте установленную eSIM.
  6. Включите Эта линия.
  7. Включите Роуминг данных.
⚠️ Для travel eSIM почти всегда нужно включать роуминг данных, иначе интернет может не работать.
Что сделать по прилёте
  1. Включите eSIM Magic eSIM.
  2. Выберите её для Сотовых данных.
  3. Включите Роуминг данных.
  4. Подождите 1–5 минут.
  5. Если сеть не появилась, включите и выключите Авиарежим.
  6. Если интернет всё ещё не работает, перезагрузите iPhone.
Если интернет не работает на iPhone
  • eSIM установлена и включена;
  • Magic eSIM выбрана для сотовых данных;
  • включён роуминг данных;
  • вы находитесь в стране, где действует тариф;
  • отключён VPN;
  • телефон не в авиарежиме;
  • есть покрытие мобильной сети.
  1. Перезагрузите iPhone.
  2. Включите и выключите авиарежим.
  3. Попробуйте выбрать сеть вручную: Настройки → Сотовая связь → Magic eSIM → Выбор сети → отключить “Автоматически” → выбрать доступную сеть.
  4. Проверьте APN, если он указан в письме с eSIM.
🤖 Инструкция по установке Magic eSIM на Android

Установка eSIM по ссылке на Android

  1. Откройте письмо на телефоне Android.
  2. Нажмите на ссылку установки eSIM.
  3. Подтвердите добавление eSIM.
  4. Дождитесь завершения установки.
  5. Назовите eSIM Magic eSIM.
  6. Перед использованием выберите её для мобильного интернета.

Установка eSIM через QR-код на Android

  1. Откройте письмо с данными eSIM на другом устройстве: компьютере, планшете или втором телефоне.
  2. На Android откройте Настройки.
  3. Перейдите в раздел Сеть и интернет, Подключения или SIM-карты и мобильные сети.
  4. Найдите пункт Добавить eSIM, Добавить SIM или Управление eSIM.
  5. Выберите Сканировать QR-код.
  6. Отсканируйте QR-код из письма.
  7. Подтвердите добавление eSIM.
  8. Дождитесь завершения установки.
  9. Назовите eSIM, например Magic eSIM или Travel.
  10. Для мобильных данных выберите Magic eSIM, когда будете готовы пользоваться тарифом.

Samsung

  1. Откройте Настройки.
  2. Перейдите в Подключения.
  3. Откройте Диспетчер SIM-карт.
  4. Нажмите Добавить eSIM.
  5. Выберите Сканировать QR-код.
  6. Отсканируйте QR-код из письма.
  7. Подтвердите добавление тарифа.
  8. После установки выберите Magic eSIM для мобильных данных.
  9. Включите Роуминг данных.

Google Pixel

  1. Откройте Настройки.
  2. Перейдите в Сеть и интернет.
  3. Нажмите SIM-карты или Мобильная сеть.
  4. Выберите Добавить SIM.
  5. Нажмите Скачать SIM-карту.
  6. Отсканируйте QR-код из письма.
  7. Подтвердите установку.
  8. Выберите Magic eSIM для мобильных данных.
  9. Включите Роуминг данных.

Xiaomi / Redmi / POCO

  1. Откройте Настройки.
  2. Перейдите в SIM-карты и мобильные сети.
  3. Найдите пункт Управление eSIM или Добавить eSIM.
  4. Выберите установку через QR-код.
  5. Отсканируйте QR-код из письма.
  6. Дождитесь добавления eSIM.
  7. Выберите Magic eSIM для мобильных данных.
  8. Включите Роуминг данных.
⚠️ На некоторых моделях Xiaomi, Redmi и POCO eSIM может не поддерживаться, даже если устройство новое.

Как включить интернет через eSIM на Android

  1. Откройте Настройки.
  2. Перейдите в раздел SIM-карты, Мобильная сеть или Диспетчер SIM-карт.
  3. Выберите Magic eSIM.
  4. Включите eSIM.
  5. Выберите Magic eSIM для мобильных данных.
  6. Включите Роуминг данных.
⚠️ Для travel eSIM почти всегда нужно включать роуминг данных, иначе интернет может не работать.

Что сделать по прилёте

  1. Включите eSIM Magic eSIM.
  2. Выберите её для мобильных данных.
  3. Включите Роуминг данных.
  4. Подождите 1–5 минут.
  5. Если сеть не появилась, включите и выключите Авиарежим.
  6. Если интернет всё ещё не работает, перезагрузите телефон.

Если интернет не работает на Android

  • eSIM установлена и включена;
  • Magic eSIM выбрана для мобильных данных;
  • включён роуминг данных;
  • вы находитесь в стране, где действует тариф;
  • отключён VPN;
  • телефон не в авиарежиме;
  • есть покрытие мобильной сети.
  1. Перезагрузите телефон.
  2. Включите и выключите авиарежим.
  3. Попробуйте выбрать сеть вручную: Настройки → Мобильная сеть → Magic eSIM → Оператор сети → отключить автоматический выбор → выбрать доступную сеть.
  4. Проверьте APN, если он указан в письме с eSIM.

❗ Важные правила

  1. Устанавливайте eSIM только при стабильном интернете.
  2. Не удаляйте eSIM, если тариф ещё нужен.
  3. Не передавайте QR-код другим людям.
  4. Один QR-код обычно устанавливается только на одно устройство.
  5. Для работы eSIM почти всегда нужно включить роуминг данных.
  6. Перед покупкой убедитесь, что телефон поддерживает eSIM.
  7. Если письмо с eSIM не пришло, проверьте папки Спам, Промоакции и Рассылки.

🆘 Что отправить в поддержку

  • модель телефона;
  • страну, где вы находитесь;
  • номер заказа;
  • скриншот письма с данными eSIM без QR-кода или с закрытым QR-кодом;
  • скриншот настроек eSIM;
  • скриншот ошибки, если она появляется;
  • описание проблемы: не устанавливается eSIM, нет сети, нет интернета или не работает QR-код.
