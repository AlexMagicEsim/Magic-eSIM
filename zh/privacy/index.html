关于本政策

本隐私政策适用于您访问 Magic eSIM 国际网站（magicesim.store/en/ 及其其他非俄语语言版本）以及您联系我们的客服团队的情形。

国际网站目前尚不提供在线购买。在开放在线购买之前，我们将发布更新的隐私政策，涵盖订单、付款和 eSIM 的交付。

网站的俄语版本有其自己的隐私政策，适用于您使用该版本的情形。

1. 我们是谁

您个人数据的控制者是：

  • 个体企业家 ALEKSANDR KHARIN，在格鲁吉亚注册，以 Magic eSIM 名义经营
  • 识别号：305887261
  • 地址：Georgia, Tbilisi, Saburtalo district, Bakhtrioni str. N22, Apt. 75
  • 隐私问题联系邮箱：support@magicesim.store

2. 我们处理哪些数据以及原因

我们不要求您创建账户。我们不会询问您的电话号码、身份证件或支付信息，也不需要您的姓名或邮寄地址。如果您在发给我们的消息中附上您的姓名或邮寄地址——例如在我们退款政策中的撤回示范表格中——提供这些信息是可选的，我们仅将其用于处理该消息。

当您浏览网站时

  • 数据：您的 IP 地址、浏览器和设备信息、您请求的页面以及请求的时间。
  • 目的：向您显示网站，并保护网站免遭滥用。
  • 法律依据：我们在运营安全网站方面的正当利益。

当您查询套餐的准确价格时

  • 数据：您选择的套餐和天数，以及您的 IP 地址和技术数据。
  • 目的：计算当前价格并将其保留 30 分钟。
  • 法律依据：我们的正当利益，以及您在可能的购买之前要求我们采取的步骤。

我们的服务器仅在内存中短暂使用您的 IP 地址，以阻止过多的请求；它不会将 IP 地址与价格请求一起保存。保存的价格记录不包含任何个人数据。

当您进行结账时

目前尚不支持在线支付，因此无法下单。在结账时，您可以输入电子邮箱地址，并勾选接受我们的服务条款和退款政策以及要求我们立即开始提供套餐的复选框。

在无法付款期间，电子邮箱地址和您勾选的复选框仅保留在您浏览器中的页面上：它们不会发送给我们，也不会保存在您浏览器的存储中。在结账时，发送到我们服务器的唯一请求是上述价格请求，其中不包含这两者中的任何一项。

当您写信给客服时

  • 数据：您的电子邮箱地址、您的消息以及任何附件。
  • 目的：回复您。
  • 法律依据：我们在答复咨询方面的正当利益，以及您在可能的购买之前要求我们采取的步骤。

日志

我们的托管服务提供商会在有限期间内保存对我们服务器的请求的技术日志（见第 6 节）。这些日志可能包含 IP 地址，偶尔也可能包含我们服务器无法处理的请求的部分内容。

我们不做的事

我们不出售个人数据，不将其用于广告或用户画像，也不发送营销邮件。我们不会出售或共享加利福尼亚州法律所定义的“出售”（sell）和“共享”（share）意义上的个人数据；无论您居住在何处，包括在美国，您都可以行使第 7 节中的权利。

3. Cookie 和本地存储

国际网站不使用 Cookie，也不使用任何分析、广告或跟踪工具。

它只在您的浏览器中存储两个很小的值：

  • mesim.site.lang（本地存储）记住您选择的语言，直至您将其清除。
  • me-logo（会话存储）使标志动画在每次访问时只播放一次，直至您关闭该标签页。

这些值仅用于让网站按您的要求显示；它们不会发送给我们。如果我们今后添加分析或类似工具，我们将先更新本政策，并在法律要求时征得您的同意。

Do Not Track（请勿跟踪）

我们不会长期跟踪您，也不会跨其他网站或在线服务跟踪您；当您使用我们的网站时，我们也不允许其他公司长期、跨不同网站收集有关您在线活动的个人数据。因此，我们不会对“Do Not Track”或 Global Privacy Control 信号作出不同的响应：无论您的浏览器是否发送此类信号，都不会发生此类跟踪。

4. 为我们处理数据的服务提供商

为运营网站和客服，我们使用以下服务提供商。每家服务提供商仅为提供其服务而处理数据。

GitHub, Inc.（美国）及其网络服务提供商 Fastly, Inc.

托管网站的页面。GitHub 还会根据其自己的隐私声明，出于其自身的安全目的记录访客的 IP 地址。数据：您访问时的 IP 地址和技术数据。

Render Services, Inc.（美国）及其网络服务提供商 Cloudflare, Inc.

运行向网站提供套餐列表和价格的服务器。数据：IP 地址、技术数据，以及您查询价格的套餐和天数。

ImprovMX Incorporated（美国）

接收发送至 support@magicesim.store 的电子邮件，并将其转发到我们的邮箱。它将投递日志保存 7 天，且仅在邮件投递完成之前保存邮件内容。数据：您的电子邮箱地址、邮件头以及传输中的邮件内容。

我们的电子邮件服务提供商

我们的客服邮箱由一家电子邮件服务提供商托管，我们的回复通过瑞士的 Proton AG 发送。数据：您的电子邮箱地址以及与我们往来的邮件。

在法律要求的情况下，或为确立或抗辩法律索赔所必需时，我们也可能披露数据。

5. 数据的跨境处理

我们位于格鲁吉亚，但我们的服务提供商是国际公司。因此，您的数据可能在格鲁吉亚境外处理，主要是在美国、欧洲经济区和瑞士，以及这些服务提供商或其自身的服务提供商开展业务的其他国家。

其中一些国家（包括美国）提供的数据保护水平可能低于格鲁吉亚或欧洲联盟。

我们为保护您的数据所采取的措施：

  • 我们收集的数据非常少：无需账户，没有分析或跟踪，没有支付数据。
  • Render 和 GitHub 参加了 EU–U.S. Data Privacy Framework（欧盟—美国数据隐私框架），欧盟委员会已认定该框架提供充分的保护水平。
  • 往返于我们网站和服务器之间的数据均经过加密（HTTPS）。

这些措施降低了上述风险，但并不能消除这些风险。

您可以写信至 support@magicesim.store，向我们索取有关这些保障措施的详细信息，包括可提供的副本。

6. 我们保存数据的期限

期限届满时，我们会删除数据或将其匿名化，通常在 30 天内完成。如果争议或法律索赔需要这些数据，我们会将其保存至该事项了结。

  • 客服邮件：最后一封邮件之后 3 年，以便我们处理后续问题和索赔。
  • 隐私请求及我们答复的记录：请求结案之后 3 年。
  • 价格记录（不含个人数据）：90 天。
  • 我们服务器的托管日志：最长 30 天。
  • 电子邮件转发日志：7 天（由 ImprovMX 设定）。
  • 网站访客日志：按照 GitHub 隐私声明中的规定。

7. 您的权利

您可以要求我们：

  • 告知我们是否处理您的数据，并提供数据副本；
  • 更正不准确的数据；
  • 删除您的数据，除非法律要求或因法律索赔我们必须保留这些数据；
  • 封存（限制）对您数据的处理；
  • 以可携带的格式向您提供您的数据；
  • 停止基于我们的正当利益处理您的数据；
  • 撤回您已作出的任何同意。

如需提出请求，请使用该请求所涉及的电子邮箱地址写信至 support@magicesim.store。在采取行动之前，我们可能会请您确认身份。提出请求是免费的。

我们会在 10 个工作日内答复；在法律允许的情况下，我们可以将该期限延长一次，并会告知您原因。对于有正当理由的请求，我们会在 3 个工作日内封存相关数据。

您可以向 State Audit Office of Georgia（格鲁吉亚国家审计署，sao.ge）或法院投诉。如果您身处欧洲联盟，您还可以向您所在国家的数据保护机构投诉。如果您身处新西兰，您可以向 Office of the Privacy Commissioner（隐私专员办公室，privacy.org.nz）投诉。

8. 安全

我们使用加密连接（HTTPS），将访问权限限制在需要的人员范围内，并且不收集支付数据。任何传输或存储方法都不是完全安全的。

9. 儿童

国际网站并非面向 18 岁以下的人士。我们不会故意收集儿童的个人数据；如果我们得知收集了此类数据，我们会将其删除。

10. 本政策的变更

当我们变更本政策时，我们会在本页面上发布新版本及其生效日期。在国际网站开放在线购买之前，我们将发布涵盖订单和付款的新版本。
