L’eSIM ne fonctionne pas : que vérifier

La plupart des problèmes viennent d’un réglage. Suivez les étapes dans l’ordre et testez Internet après chacune. Ne supprimez pas l’eSIM pendant que vous cherchez le problème.

La liste

  1. La ligne eSIM est-elle activée ? Vérifiez dans les réglages SIM.
  2. L’eSIM est-elle choisie pour les données mobiles ? Internet doit passer par l’eSIM, pas par votre SIM principale.
  3. L’itinérance des données est-elle activée sur l’eSIM ? Les eSIM de voyage se connectent généralement via des réseaux partenaires, et le téléphone considère cela comme de l’itinérance.
  4. Activez le mode Avion pendant dix secondes, puis désactivez-le.
  5. Redémarrez le téléphone.
  6. Choisissez un réseau à la main. Dans les réglages réseau de l’eSIM, désactivez la sélection automatique et choisissez un autre réseau dans la liste.
  7. Vérifiez l’APN, uniquement si les informations de votre forfait en indiquent un : il doit correspondre dans les réglages de l’eSIM.
  8. Êtes-vous dans la zone de couverture du forfait ? Vérifiez que le pays où vous vous trouvez fait partie des pays couverts par le forfait.

Du réseau, mais pas d’Internet

Le téléphone est enregistré, mais les données ne passent pas. Le plus souvent, l’eSIM n’est pas la ligne choisie pour les données mobiles, ou son itinérance des données est désactivée. Vérifiez les deux, puis activez et désactivez le mode Avion.

Ne supprimez pas l’eSIM

Supprimer l’eSIM ne résout presque jamais rien, et son code QR peut être à usage unique : vous risquez de ne pas pouvoir la réinstaller. Laissez-la installée pendant que vous suivez la liste.

Toujours pas de connexion ?

Si vous avez suivi toute la liste et que l’eSIM ne fonctionne toujours pas, écrivez-nous à support@magicesim.store.

Questions

L’eSIM affiche « Aucun service ». Que faire en premier ?

Vérifiez que l’itinérance des données est activée sur l’eSIM, activez puis désactivez le mode Avion et attendez quelques minutes. Essayez ensuite de choisir un réseau à la main.

Puis-je réinstaller l’eSIM avec le même code QR ?

Souvent non : un code QR peut être à usage unique. C’est pourquoi la liste vous dit de ne pas supprimer l’eSIM.

Ma SIM principale peut-elle me coûter quelque chose pendant que je cherche le problème ?

Si la SIM principale est choisie pour les données mobiles et que son itinérance des données est activée, votre opérateur habituel peut vous facturer. Gardez l’eSIM comme ligne de données ou désactivez l’itinérance des données sur la SIM principale.
