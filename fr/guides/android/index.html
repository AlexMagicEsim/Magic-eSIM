Installer une eSIM sur Android

Chaque marque Android nomme ses réglages différemment, mais les étapes sont les mêmes : trouvez où se gèrent les SIM, ajoutez une eSIM avec son code QR ou à la main, puis choisissez-la pour les données mobiles à destination. L’installation nécessite une connexion Internet, le plus simple étant un réseau Wi-Fi.

Trouvez où se gèrent les SIM

Les réglages SIM se trouvent généralement à l’un de ces endroits ; les noms varient selon la marque et la version d’Android :

  • Google Pixel : Paramètres → Réseau et Internet → Cartes SIM → Ajouter une carte SIM → Configurer une eSIM.
  • Samsung Galaxy : Paramètres → Connexions → Gestionnaire SIM → Ajouter une eSIM (sur les versions plus anciennes de One UI : Gestionnaire de carte SIM → Ajout d’un forfait mobile).
  • Autres marques : cherchez dans les réglages « Réseau mobile », « Cartes SIM » ou « Connexions ».

Si vous ne trouvez nulle part l’option pour ajouter une eSIM, vérifiez si votre téléphone est compatible eSIM.

Installez l’eSIM

  1. Affichez le code QR de votre eSIM sur un autre écran.
  2. Commencez à ajouter une eSIM comme indiqué ci-dessus. Samsung : touchez Scanner le code QR (sur les versions plus anciennes : Numérisation code QR opérateur) et scannez le code. Pixel : suivez les instructions à l’écran.
  3. Pas de code QR à scanner ? Sur Samsung, touchez Entrer le code d’activation et saisissez les données fournies avec votre eSIM (sur les versions plus anciennes de One UI, suivez l’option proposée à l’écran pour saisir un code d’activation).
  4. Confirmez et attendez la fin de l’installation.
  5. Renommez l’eSIM, par exemple « Voyage ».

À destination : activez les données

  1. Vérifiez que l’eSIM est activée. Pixel : Paramètres → Réseau et Internet → Réseau mobile → l’eSIM → Utiliser cette carte SIM.
  2. Choisissez l’eSIM comme SIM pour les données mobiles. Pixel : Paramètres → Réseau et Internet → Cartes SIM → Données mobiles. Votre SIM principale peut rester active pour les appels et les SMS.
  3. Activez l’itinérance pour l’eSIM. Pixel : Paramètres → Réseau et Internet → Cartes SIM (ou Profils SIM) → Itinérance. Samsung : cherchez le réglage dans les paramètres de réseau mobile sous Connexions ; son nom exact dépend du modèle. Les eSIM de voyage se connectent généralement via des réseaux partenaires, et le téléphone considère cela comme de l’itinérance.
  4. Si vous ne voulez pas de frais de votre opérateur habituel, désactivez l’itinérance des données sur votre SIM principale.
  5. Attendez une ou deux minutes que le téléphone s’enregistre sur un réseau local.

Si quelque chose ne fonctionne pas

Vérifiez la SIM choisie pour les données et l’itinérance de l’eSIM, activez puis désactivez le mode Avion et redémarrez le téléphone. La liste complète se trouve dans L’eSIM ne fonctionne pas.

Ne supprimez pas l’eSIM pendant que vous cherchez le problème : son code QR peut être à usage unique.

Questions

Mon téléphone Android n’a pas d’option pour ajouter une eSIM. Que faire ?

Parcourez tous les menus liés à la SIM : leur nom varie selon la marque. Si aucun ne propose d’ajouter ou de télécharger une eSIM, le téléphone (ou cette version régionale) n’est probablement pas compatible eSIM.

Puis-je utiliser l’eSIM et ma SIM physique en même temps ?

Sur les téléphones double SIM compatibles eSIM, oui : choisissez l’eSIM pour les données mobiles et gardez la SIM physique pour les appels et les SMS.

Dois-je configurer un APN ?

Seulement si les informations de votre forfait indiquent un APN : vérifiez alors qu’il correspond dans les réglages de l’eSIM.
