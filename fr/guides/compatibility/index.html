Votre téléphone est-il compatible eSIM ?

La vérification la plus courte : ouvrez les réglages SIM et cherchez l’option pour ajouter une eSIM. Si elle est présente, le téléphone est compatible eSIM. Profitez-en pour vérifier deux autres points : le téléphone est-il verrouillé par un opérateur, et de quelle version régionale s’agit-il ?

Vérification 1 : le réglage

iPhone : Réglages → Données cellulaires (au Canada, Réseau cellulaire). Si Ajouter une eSIM ou Ajouter un forfait cellulaire apparaît, l’iPhone est compatible eSIM.

Android : ouvrez les réglages SIM et cherchez comment ajouter une eSIM : sur Pixel, Réseau et Internet → Cartes SIM → Ajouter une carte SIM → Configurer une eSIM ; sur Samsung, Connexions → Gestionnaire SIM → Ajouter une eSIM (sur les versions plus anciennes de One UI : Gestionnaire de carte SIM → Ajout d’un forfait mobile).

Autre indice sur Pixel : pour utiliser une eSIM, le téléphone doit disposer d’un numéro EID. Vous le trouverez dans Paramètres → À propos du téléphone → État de la carte SIM. Mais c’est le réglage pour ajouter une eSIM qui fait foi.

Vérification 2 : est-il verrouillé par un opérateur ?

Un téléphone acheté avec un abonnement peut être verrouillé par son opérateur et refuser les autres SIM et eSIM jusqu’à son déverrouillage.

Sur iPhone, ouvrez Réglages → Général → Informations et cherchez « Aucune restriction de SIM » en regard de Verrouillage de l’opérateur. Sur Android, renseignez-vous auprès de l’opérateur qui a vendu le téléphone.

Vérification 3 : la version régionale

Un même modèle peut avoir l’eSIM dans un pays et pas dans un autre : la compatibilité dépend du marché pour lequel le téléphone a été fabriqué, pas seulement de son nom. C’est pourquoi nous ne publions pas de liste de « modèles compatibles » : ce sont les réglages de votre propre téléphone qui font foi.

Questions

Mon téléphone accepte deux cartes SIM. Est-il compatible eSIM ?

Pas forcément : certains téléphones ont deux emplacements physiques et pas d’eSIM. Cherchez l’option pour ajouter une eSIM dans les réglages SIM.

Je ne trouve pas l’EID. Cela veut-il dire qu’il n’y a pas d’eSIM ?

Pas forcément. Ce qui fait foi, c’est l’option pour ajouter une eSIM dans les réglages.

Et si mon téléphone n’est pas compatible eSIM ?

Une eSIM de voyage n’y fonctionnera pas. Il vous faudrait un autre téléphone compatible eSIM ou une SIM physique locale à destination.
