Installer une eSIM sur iPhone

L’installation prend quelques minutes et nécessite une connexion Internet, le plus simple étant un réseau Wi-Fi. Voici tout le processus : vérifier que votre iPhone est compatible eSIM, installer le profil et activer les données cellulaires à destination.

Vérifiez que votre iPhone est compatible eSIM

Ouvrez Réglages → Données cellulaires (ou Données mobiles ; au Canada, Réseau cellulaire). Si vous y voyez Ajouter une eSIM ou Ajouter un forfait cellulaire, votre iPhone est compatible eSIM.

Votre iPhone ne doit pas non plus être verrouillé par un opérateur. Voir comment vérifier la compatibilité.

Option 1 : scannez le code QR

  1. Affichez le code QR de votre eSIM sur un autre écran : un ordinateur, une tablette ou un autre téléphone.
  2. Sur l’iPhone, ouvrez l’app Appareil photo et scannez le code QR.
  3. Lorsque la notification Forfait cellulaire détecté apparaît, touchez-la.
  4. Touchez Continuer, puis Ajouter un forfait cellulaire. Si un code de confirmation vous est demandé, saisissez celui indiqué avec votre eSIM.
  5. Donnez à la ligne un nom clair, par exemple « Voyage », pour ne pas la confondre avec votre SIM principale.

Avec iOS 17.4 ou une version ultérieure, si le code QR se trouve dans un e-mail ou sur une page web de cet iPhone, touchez le code de façon prolongée, puis touchez Ajouter une eSIM.

Option 2 : saisissez les données à la main

  1. Munissez-vous des données d’installation manuelle fournies avec votre eSIM.
  2. Ouvrez Réglages → Données cellulaires (ou Données mobiles) et touchez Ajouter un forfait cellulaire.
  3. Touchez Saisir les données manuellement (au Canada, Saisir les détails manuellement) et saisissez ces données.
  4. Confirmez et attendez la fin de l’installation.

Pratique lorsque vous n’avez pas de code QR à scanner.

À destination : activez les données

  1. Dans Réglages → Données cellulaires, vérifiez que la ligne eSIM est activée.
  2. Touchez Données cellulaires et choisissez la ligne eSIM. Votre SIM principale peut rester active pour les appels et les SMS.
  3. Ouvrez la ligne eSIM et activez l’itinérance des données. Les eSIM de voyage se connectent généralement via des réseaux partenaires, et le téléphone considère cela comme de l’itinérance.
  4. Si vous ne voulez pas de frais de votre opérateur habituel, désactivez l’itinérance des données sur votre SIM principale.
  5. Attendez une ou deux minutes que le téléphone s’enregistre sur un réseau local.

Les noms des menus peuvent légèrement varier selon la version d’iOS.

Si quelque chose ne fonctionne pas

Vérifiez que l’eSIM est la ligne choisie pour les données et que son itinérance des données est activée, puis redémarrez le téléphone. La liste complète se trouve dans L’eSIM ne fonctionne pas.

Ne supprimez pas l’eSIM pendant que vous cherchez le problème : son code QR peut être à usage unique, et vous risquez de ne pas pouvoir la réinstaller.

Questions

Faut-il du Wi-Fi pour installer une eSIM sur iPhone ?

Il faut une connexion Internet pour télécharger le profil, le plus simple étant un réseau Wi-Fi. Si vous installez l’eSIM le jour du voyage, chez vous avant de partir ou avec le Wi-Fi de l’aéroport, cela convient à tous les forfaits, quel que soit le moment où leur validité commence.

Le code QR est sur ce même iPhone. Puis-je quand même installer l’eSIM ?

Oui. Avec iOS 17.4 ou une version ultérieure, touchez de façon prolongée le code QR dans l’e-mail ou sur la page web, puis touchez Ajouter une eSIM. Vous pouvez aussi choisir Saisir les données manuellement et saisir les données fournies avec votre eSIM.

Que devient mon numéro principal ?

Il reste actif. Les appels et les SMS vers votre numéro principal suivent les conditions d’itinérance de votre opérateur habituel ; l’eSIM de voyage sert aux données cellulaires.

Pourquoi activer l’itinérance des données sur l’eSIM ?

Les eSIM de voyage se connectent généralement via des réseaux partenaires, et le téléphone considère cela comme de l’itinérance. L’itinérance des données sur la ligne eSIM est un réglage normal ; sur votre SIM principale, vous pouvez la laisser désactivée.
